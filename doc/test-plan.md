# План тестирования

Тест-кейсы из методички с результатами проверки на версии v1.1.

| ID | Название | Предусловие | Шаги | Ожидаемый результат | Результат |
|---|---|---|---|---|---|
| TC-01 | Регистрация нового пользователя | Приложение запущено, открыт экран регистрации | 1. Ввести логин. 2. Ввести пароль. 3. Нажать «Зарегистрироваться» | Toast «Регистрация успешна», переход на главный экран, запись в таблице Users | Пройден |
| TC-02 | Валидация пустых полей | Открыт экран авторизации | 1. Оставить поля «Логин» и «Пароль» пустыми. 2. Нажать «Войти» | Ошибка setError() на полях, вход не выполняется | Пройден |
| TC-03 | Добавление элемента в БД | Пользователь авторизован, открыта форма добавления | 1. Заполнить все поля формы. 2. Нажать «Сохранить» | Экран закрывается, рецепт появляется в списке, строка добавлена в таблицу Recipes | Пройден |
| TC-04 | Сохранение состояния | Открыта форма добавления с заполненными полями и выбранной категорией | 1. Повернуть устройство в альбомную ориентацию | Интерфейс перестраивается, введённый текст, категория и фото не стираются | Пройден |
| TC-05 | Удаление элемента | Открыт список рецептов | 1. Нажать «Удалить» | Рецепт исчезает из списка, появляется Snackbar, строка удалена из таблицы | Пройден |
| TC-06 | Фильтр по дате | Открыт экран «Рецепты», есть рецепты | 1. Нажать кнопку периода и выбрать диапазон с рецептами. 2. Нажать «Сбросить» | Список фильтруется по периоду, после сброса все рецепты возвращаются | Пройден |
| TC-07 | Переключение разделов | Пользователь авторизован | 1. Переключиться «Рецепты» ↔ «Профиль» несколько раз. 2. Ввести текст в поиске и вернуться | Экраны переключаются без ошибок, поиск и фильтр работают | Пройден |
