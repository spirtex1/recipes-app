# Руководство пользователя

## Первый запуск

При первом запуске открывается экран авторизации. Если учётной записи нет, введите логин и пароль и нажмите «Регистрация». После регистрации откроется главный экран.

Если учётная запись уже есть, введите логин и пароль и нажмите «Войти». Приложение запомнит вход, и при следующем запуске экран авторизации пропускается.

## Главный экран

Главный экран показывает список ваших рецептов. Внизу две вкладки:

- **Рецепты** — текущий экран со списком.
- **Профиль** — меню с пунктами: сменить тему, статистика, выход.

Над списком есть строка поиска и фильтр по категории. Поиск ищет по названию, фильтр показывает рецепты выбранной категории. Их можно использовать вместе.

## Добавление рецепта

Нажмите «Добавить рецепт». Заполните поля:

- **Название** — обязательно.
- **Время готовки, мин** — обязательно, число больше нуля.
- **Описание** — ингредиенты и шаги приготовления, необязательно.
- **Категория** — выберите из списка.

Нажмите «Сохранить». Рецепт появится в списке.

## Просмотр, редактирование и удаление

- Нажмите на рецепт, откроется экран с подробностями: название, категория, время и описание.
- На экране подробностей нажмите «Изменить», чтобы поправить рецепт, и «Сохранить».
- В карточке рецепта нажмите «Удалить», чтобы его убрать. Внизу появится сообщение «Рецепт удалён».

## Профиль

- **Сменить тему** — переключает светлую и тёмную тему. Выбор сохраняется.
- **Статистика** — показывает количество рецептов в каждой категории.
- **Выйти** — завершает сессию и возвращает на экран входа.
- **Панель администратора** — доступна только администратору.

## Ориентация экрана

Приложение поддерживает портретную и альбомную ориентацию. При повороте список и введённые данные сохраняются.
