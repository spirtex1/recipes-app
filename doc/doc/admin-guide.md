# Руководство системного администратора

## Системные требования

- Android 7.0 (API 24) и выше.
- Оперативная память от 2 ГБ.
- Свободное место от 50 МБ.

## Установка

Установка выполняется одним из способов:

1. Через Android Studio: откройте проект и нажмите Run, выбрав устройство.
2. Перенос APK-файла из раздела Releases на устройство и запуск установки.

Для установки APK на устройстве нужно разрешить установку из неизвестных источников.

## База данных

Данные хранятся в SQLite-файле `recipes.db`, который создаётся приложением автоматически при первом запуске. Путь на устройстве:

`/data/data/ru.shtrih.recipesapp/databases/recipes.db`

Доступ к файлу без root-прав недоступен, это стандартная изоляция Android.

### Таблицы

- **Users** — пользователи: id, логин, пароль, роль (`user` или `admin`).
- **Categories** — категории рецептов: id, название. Создаются автоматически: Завтрак, Обед, Ужин, Десерт.
- **Recipes** — рецепты: id, название, описание, время готовки, id категории, id пользователя. Связаны с Categories и Users через внешние ключи.

### Версии схемы

- Версия 1: таблица Users.
- Версия 2: таблицы Categories и Recipes.
- Версия 3: поле роли в Users и учётная запись администратора.

При обновлении приложения база мигрирует автоматически, данные пользователей сохраняются.

## Учётная запись администратора

При создании базы автоматически создаётся администратор:

- Логин: `admin`
- Пароль: `admin123`

Рекомендуется сменить пароль в реальной эксплуатации. В текущей версии смена пароля не реализована, пароль хранится в открытом виде.

## Панель администратора

Доступна из меню «Профиль» только пользователям с ролью `admin`. Показывает общее количество пользователей и рецептов, а также список логинов с ролями.

## Удаление приложения и данных

Удаление приложения с устройства также удаляет базу данных. Очистка данных приложения в настройках Android приводит к тому же результату.
