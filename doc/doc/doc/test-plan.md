# План тестирования

Тест-кейсы из методички с результатами проверки.

| ID | Название | Предусловие | Шаги | Ожидаемый результат | Результат |
|---|---|---|---|---|---|
| TC-01 | Регистрация нового пользователя | Приложение запущено, открыт экран регистрации | 1. Ввести логин. 2. Ввести пароль. 3. Нажать «Регистрация» | Toast «Регистрация успешна», переход на главный экран, запись в таблице Users | Пройден |
| TC-02 | Валидация пустых полей | Открыт экран авторизации | 1. Оставить поля пустыми. 2. Нажать «Войти» | Ошибка setError() на полях, вход не выполняется | Пройден |
| TC-03 | Добавление элемента в БД | Пользователь авторизован, открыта форма добавления | 1. Заполнить поля. 2. Нажать «Сохранить» | Экран закрывается, рецепт появляется в списке, строка в таблице Recipes | Пройден |
| TC-04 | Сохранение состояния | Открыт список рецептов | 1. Повернуть устройство в альбомную ориентацию | Интерфейс перестраивается, список не теряется и не падает | Пройден |
| TC-05 | Удаление элемента | Открыт список рецептов | 1. Нажать «Удалить» | Рецепт исчезает из списка, появляется Snackbar, строка удалена из таблицы | Пройден |

## Дополнительные проверки

| ID | Название | Результат |
|---|---|---|
| ADD-01 | Поиск по названию | Пройден: список фильтруется по введённому тексту |
| ADD-02 | Фильтр по категории вместе с поиском | Пройден |
| ADD-03 | Редактирование рецепта | Пройден: поля заполняются, изменения сохраняются |
| ADD-04 | Переключение темы | Пройден: тема меняется и сохраняется после перезапуска |
| ADD-05 | Сессия | Пройден: после перезапуска вход не требуется |

## Неприменимые требования

Фильтрация по датам (из блока 5) для темы «Рецепты» не применяется: рецепты не имеют даты создания как бизнес-события, а фильтр по категории реализован.
