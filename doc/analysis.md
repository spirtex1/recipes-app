# Анализ предметной области

## Назначение приложения

Приложение предназначено для автоматизации процессов с мобильных устройств под управлением ОС Android. Целью является повышение эффективности взаимодействия пользователя с сервисом путём предоставления автономного мобильного интерфейса с локальным хранением данных.

## Роли пользователей

- **Клиент:** регистрация, просмотр рецептов, создание и редактирование рецептов, составление плана питания.
- **Администратор:** управление справочниками (категории, ингредиенты), просмотр и модерация пользовательских рецептов.

## Схема таблиц БД

| Таблица | Поля | Связи |
|---|---|---|
| Users | id, login, password | — |
| Categories | id, name | — |
| Recipes | id, title, description, cook_time, category_id, user_id | category_id → Categories.id, user_id → Users.id |
| Ingredients | id, name, unit | — |
| RecipeIngredients | recipe_id, ingredient_id, amount | recipe_id → Recipes.id, ingredient_id → Ingredients.id |
| MealPlan | id, date, meal_type, recipe_id | recipe_id → Recipes.id |

## Связи между таблицами

- Один пользователь может создать много рецептов (Users → Recipes, 1:N).
- Каждый рецепт относится к одной категории (Categories → Recipes, 1:N).
- Рецепт содержит много ингредиентов, и ингредиент входит во много рецептов (Recipes ↔ Ingredients, N:M через RecipeIngredients).
- Рецепт может быть запланирован на несколько дат (Recipes → MealPlan, 1:N).
